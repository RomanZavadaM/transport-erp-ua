# Glossary

**Trip** — один конкретний рейс на конкретну дату/час.  
**Duty** — наряд / виробнича зміна автобуса та екіпажу, яка містить один або кілька рейсів.  
**Release** — процедура допуску Duty до виїзду.  
**Waybill** — шляховий лист, прив'язаний до Duty та його рейсів.  
**Plan** — заплановані дані.  
**Fact** — фактично виконані дані.  
**Snapshot** — незмінне історичне представлення факту/документа.  
**Correction Case** — контрольований процес виправлення закритих історичних даних без їх переписування.  
**Invariant** — правило, порушення якого система не повинна допустити ні через UI, ні через API, ні через конкурентну операцію.
