# Project Charter

## Мета

Створити production-ready вебсистему транспортного підприємства для планування та обліку рейсів, випуску автобусів, роботи водіїв, шляхових листів, фактичного руху, пробігу, пального, ТО/ремонтів, документів, аудиту та звітності.

## Критерій успіху MVP

Один наскрізний production workflow:

Планування → Duty → автобус/водій → медичний/технічний контроль → дозвіл → шляховий лист → виїзд → рейси → повернення → закриття → звіт.
