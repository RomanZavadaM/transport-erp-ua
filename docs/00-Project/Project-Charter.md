# Project Charter

## Мета

Створити production-ready ERP транспортного підприємства для планування та обліку рейсів, випуску автобусів, роботи водіїв, шляхових листів, фактичного руху, пробігу, пального, ТО/ремонтів, документів, аудиту та звітності.

## Форма продукту

Базовий локальний рівень — **встановлюваний desktop-застосунок TransportERP-UA** з SQLite та локальним сховищем документів.

Web-технології можуть використовуватися всередині UI/desktop shell, але користувач малого/локального АТП працює з програмою, а не з вкладкою `localhost` у браузері.

Центральний/server рівень є опційним і додається тоді, коли підприємству потрібна консолідація або вища ланка управління.

## Масштаб підприємства

Одна кодова база повинна бути практично придатною від малого АТП приблизно на 5–10 машин до великого підприємства з кількома локальними вузлами.

## Критерій успіху MVP

Один наскрізний production workflow:

Планування → Duty → автобус/водій → медичний/технічний контроль → дозвіл → шляховий лист → виїзд → рейси → повернення → закриття → звіт.

Для Local Desktop цей workflow повинен працювати без PostgreSQL, Docker, Redis, S3 та без постійного Internet.
