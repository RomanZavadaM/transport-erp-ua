# ADR-0006 — Українська як канонічна мова та багатомовність

## Статус
Прийнято.

## Рішення
Українська (`uk`) є канонічною мовою проєкту, документації, бізнес-вимог і початкового інтерфейсу.

Система архітектурно підтримує локалі:

- `uk` — українська, основна;
- `en` — англійська;
- `es` — іспанська;
- `fr` — французька;
- `de` — німецька.

## Правила

1. Бізнес-правило має один стабільний ID незалежно від мови.
2. API повертає стабільні machine-readable error codes; локалізація повідомлень виконується presentation layer.
3. Status та enum values у БД/API не перекладаються і залишаються стабільними технічними кодами.
4. UI-тексти зберігаються у locale resources, а не hardcode-яться у компонентах.
5. Шаблони документів можуть мати окремі locale/version, але українські юридично значимі форми є первинними для українського deployment.
6. У разі розбіжності документації український канон має пріоритет.

## Наслідки
Багатомовність не створює окремих реалізацій бізнес-логіки. Один domain core обслуговує всі локалі.
