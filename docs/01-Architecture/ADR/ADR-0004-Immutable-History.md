# ADR-0004 — Незмінна історія

## Статус
Прийнято.

## Рішення
Закриті історичні дані та версії документів не переписуються. Виправлення створюють нову версію або snapshot із посиланням на попередній стан і причину корекції.

## Наслідки
- закритий рейс не відкривається для тихого редагування;
- закритий шляховий лист не переписується;
- correction workflow створює нову версію;
- попередні версії залишаються доступними для аудиту.
