# ADR-0001-Modular-Monolith

## Status
Accepted

## Decision
Вибрати modular monolith замість мікросервісів.

## Rationale
Менша операційна складність при збереженні чітких доменних меж.

## Consequences
Рішення є частиною architecture freeze. Зміна потребує нового ADR, а не тихого редагування цього документа.
