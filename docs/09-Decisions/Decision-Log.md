# Журнал рішень

Архітектурні рішення фіксуються окремими ADR.

Поточні прийняті рішення:

- ADR-0001 — модульний моноліт;
- ADR-0002 — PostgreSQL як транзакційне джерело істини;
- ADR-0003 — Duty як окремий агрегат від Trip;
- ADR-0004 — незмінна історія та версійні корекції;
- ADR-0005 — командний API для критичних операцій;
- ADR-0006 — українська як канонічна мова та i18n `uk/en/es/fr/de`.

Accepted ADR не редагується так, щоб приховати старе рішення. Зміна фундаментального рішення оформлюється новим ADR із посиланням на попередній.
