# Dispatcher Board

Головний екран диспетчера орієнтований на операційний день, а не на CRUD-таблиці.

Основні колонки/сигнали:

- час;
- маршрут і рейс;
- Duty;
- автобус;
- водій;
- документи;
- передрейсові перевірки;
- стан випуску;
- план / факт;
- відхилення та блокування.

Колір є лише допоміжним індикатором. Причина блокування завжди відображається текстом.

Concurrent updates мають оновлювати board без непомітного перетирання змін; для server→browser подій базово розглядаємо SSE.
