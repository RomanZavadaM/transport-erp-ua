# Release Workspace

Одна робоча сторінка повинна зводити всі умови випуску Duty:

- Duty та рейси;
- призначений автобус;
- призначені водії;
- стан потрібних документів;
- результати передрейсових перевірок;
- blocking defects / operational blocks;
- compliance evaluation;
- шляховий лист;
- авторизація диспетчера.

Кнопка авторизації не змінює статус локально. Вона викликає серверну business command, яка повторно перевіряє актуальні умови всередині транзакції.
