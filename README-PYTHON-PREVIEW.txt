TransportERP-UA — Python Preview

Це поточна тестова збірка для ручного огляду під час розробки.
EXE не потрібен.

Запуск у Windows:
1. Повністю розпакуйте ZIP у звичайну папку.
2. Запустіть START_WINDOWS.bat.
3. Перший запуск створить локальне середовище .venv та встановить Python-залежності.
4. Наступні запуски виконуються тим самим START_WINDOWS.bat.

Потрібно на ПК:
- Python 3.12 або новіший.
- Internet потрібен лише при першому встановленні Python-залежностей або якщо вони змінилися.
- Node.js для цього ZIP НЕ потрібен: frontend уже зібраний та вкладений у пакет.

ВАЖЛИВО ПРО ДАНІ:
- база даних НЕ зберігається у папці версії;
- усі r1/r2/r3/... використовують одну постійну папку даних;
- Windows: %LOCALAPPDATA%\TransportERP-UA
- база: %LOCALAPPDATA%\TransportERP-UA\transport-erp.sqlite3
- документи: %LOCALAPPDATA%\TransportERP-UA\documents
- резервні копії: %LOCALAPPDATA%\TransportERP-UA\backups
- зміна або видалення папки тестової версії не повинна видаляти робочі дані.

Для швидкого відкриття постійної папки даних використовуйте OPEN_DATA_FOLDER.bat.

Під час розробки:
- поточні preview-версії запускаємо через Python/.venv;
- кожна тестова версія має власну .venv у своїй папці;
- робочі дані спільні між версіями і лежать окремо;
- окремий Windows EXE збираємо лише на контрольних зрізах приблизно раз на 5–10 версій.

Правило архівів:
- кожна preview-версія має унікальну назву ZIP;
- всередині ZIP завжди одна коренева папка з тією самою версією, щоб різні збірки не змішувалися;
- жодні *.db, *.sqlite або *.sqlite3 не включаються у дистрибутив.
